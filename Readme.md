# What to Watch

Учебно-практический SPA-проект каталога фильмов, реализованный на **React + TypeScript**  
с акцентом на архитектуру, управление состоянием и асинхронные данные.

## 🚀 Demo
https://what-to-watch-main.vercel.app/

## 🛠 Стек
- React
- TypeScript
- Redux
- React Router
- REST API
- ESLint / Jest

## ✨ Функциональность
- Каталог фильмов с детальными страницами
- Асинхронная загрузка данных с сервера
- Управление глобальным состоянием через Redux
- Навигация и маршрутизация между страницами
- Обработка состояний загрузки и ошибок
- Разделение UI и бизнес-логики

## 📂 Структура проекта
Проект организован по модульному принципу:  
компоненты, страницы, хранилище и асинхронная логика разделены для упрощения поддержки и масштабирования.
